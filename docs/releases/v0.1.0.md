# 旅衡 MoonTrip v0.1.0

杭州 / 成都首个固定发布基线：选城市和旅行节奏，生成含午晚餐、交通估算和预算的路书，按需加入 / 替换地点、预览、锁定、撤销与导出。

- MoonBit实现核心推荐、约束、餐饮安排、路线重排和费用计算。
- 每日真实地图底图、地点编号、餐厅颜色、坐标显示转换；底图失败可用备用简图。
- 两城来源资料、41条景点证据，保存费用、预约、闭馆与来源日期的区别。
- README、接口资料、2026-10-14测试记录和45秒实际页面分步演示。

验证：70项MoonBit、23项Python测试，六种城市 / 模式组合、景点证据、地图适配和DOM交互通过；公网两城地图及替换 / 接受 / 撤销实际操作、390像素手机视口验收。

## 下载与使用

- `moontrip-v0.1.0-public.zip`：已编译公开前端，不含密钥或本地服务。解压后在该目录运行 `python3 -m http.server 8787`，打开 `http://127.0.0.1:8787/`。无需MoonBit工具链即可查看，不要直接双击index.html。
- `moontrip-v0.1.0.mp4`：45秒、H.264、1280×864，实际页面截图编排，无旁白，非连续录屏。
- `SHA256SUMS.txt`：两个附件的校验摘要。
- GitHub自动提供的源码压缩包 / v0.1.0标签：完整源码，本地构建见README，已验证MoonBit版本0.1.20261012。

固定标签不会跟随main变化；在线演示随main更新。[在线使用](https://kleinrat.github.io/Traveling/)

## 当前范围

两城有限候选，费用为来源估算，不含住宿。虚线是顺序，真实交通候选和AI仅本地配置后可用，公网没有AI后端。未自动查询天气、节假日、每周闭馆规则、预约余量与排队；未知费用及复杂场馆留待补充。地图需联网，离线路书不含地图瓦片；核心采用贪心规划，不保证全局最优。

开源自研代码MIT；地图显示库Leaflet BSD-2-Clause，底图保留OpenStreetMap contributors署名；第三方地点资料按原来源使用条件处理。
