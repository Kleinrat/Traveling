# 开发路线与验收演示

## 当前可验证的原型

MoonBit 内核 → 条件提议 → 策略比较 → 用户选择 → 重排校验 → 费用分项 → 离线路书。
数据来自本地原创示例和用户提供的来源资料；不依赖密钥也能完整演示手动流程。

演示步骤：
1. 启动应用，选杭州或成都。
2. 设定晚起、慢游、每天两个景点，比较三种推荐取向。
3. 勾选心仪地点，排除不想去的地点，使用行程里的移除 / 优先 / 顺序按钮调整。
4. 将预算改到无法容纳心仪地点，展示冲突提示，而不是悄悄丢弃选择。
5. 添加带来源的午餐候选，选择不辣或素食，查看费用分项及来源链接。
6. 导出 HTML，断网打开；导出 JSON，保留资料及条件。
7. 配置真实 AI 服务后，描述风格与习惯，确认条件提议，再重复以上步骤。

## 后续迭代（不要当作已实现）

- 首先选择真实 AI 服务，完善歧义澄清和用户习惯档案。
- 补充公开授权数据或用户授权的数据接入，保存来源、核对日期和冲突信息。
- 多平台网页发现与交叉核实必须有实际接口或用户授权的浏览流程，不伪造平台检索。
- 加入早餐 / 晚餐、营业日期、排队、住宿 / 大交通预算和地图接驳。
- 增加精确或束搜索规划策略，减少贪心导致的非最优结果。
- 在已有 MoonBit API 上实现更精细的日期移动和手工时间锁定。
- 完成本人报名材料及验收演示，核对 2026-10-31 的官方截止口径。
