# 旅衡 MoonTrip

选城市，描述旅行风格与习惯，比较候选方案，自己选定地点并调整行程。
MoonTrip 是以 **MoonBit 为主要实现语言** 的开源旅行规划应用和可复用规划库。

## 已实现

- 城市、兴趣、每日作息、每天景点上限、亲子、雨天和慢游条件。
- 均衡、预算优先、兴趣优先三种方案比较。不同策略可能得出相同方案。
- 心仪地点锁定、排除、移除、顺序调整；不可行的选择会返回明确冲突。
- 午餐 / 晚餐候选安排和素食 / 不辣标签筛选；景点、餐饮与接驳费用分项计算。
- 带来源链接的餐厅资料卡：保存用户核对的餐厅信息与原始网页链接。
- 本地保存条件与资料，导入 JSON，导出 JSON、Markdown 和单文件离线路书。
- 可配置的 OpenAI 兼容 AI 接口：自然语言 → 条件提议 → 用户确认 → MoonBit 校验规划。
- 无密钥时，手动条件和完整行程演示仍然可运行。

**当前版本是可运行的原型。默认杭州、成都的 23 条数据是原创虚构测试资料。点击“载入杭州真实资料”可替换杭州示例：当前来源快照包含 21 个景点、14 家餐饮地点，其中 21 条具备试规划所需的费用与时段，14 条因信息不足保留待补充。所有消费、时长和交通都是估算；不将缺失信息改成免费或全天开放。其他城市需导入或添加资料。**

## 快速运行

需要 MoonBit、Node.js 22+、Python 3.9+。没有前端依赖，不需要安装 npm 包。
MoonBit 安装见 [官方工具链页面](https://www.moonbitlang.com/download/)。

```sh
git clone https://github.com/Kleinrat/Traveling.git
cd Traveling
sh scripts/build.sh
python3 scripts/serve.py
```

打开 `http://127.0.0.1:8787`。
构建生成的 `web/engine.js` 来自 MoonBit 源码，不提交到仓库。
本地构建已验证工具链版本：`moon 0.1.20260920`。

```sh
moon test --target js
python3 -m unittest discover -s scripts -p "test_*.py"
node scripts/smoke.mjs
node scripts/check_hangzhou.mjs
moon run src/main --target js
```

如果 Node 不在默认路径，可设置 `MOONTRIP_NODE=/absolute/path/to/node`。

## 三个完整使用场景

1. **周末低预算游**：选杭州、两天，文化与自然兴趣，控制活动预算；
   比较三种方案，勾选心仪景点，删掉不想去的地点，再查看费用与来源。
2. **亲子慢游**：选成都，晚一点出门，每天最多两个景点，开启亲子和慢游，
   开启午餐并选择不辣；选择餐厅，调整地点优先级，观察路线和预算变化。
3. **雨天调整**：勾选“雨天友好”，改为室内行程；导入更多室内地点，
   保留心仪地点、替换户外活动，导出离线路书在手机或电脑上查看。

## AI 服务

已支持 Kimi K2.6；也可连接支持 `/chat/completions` 和 JSON 输出的 OpenAI 兼容服务即可。
密钥只由本地 Python 传输层读取，不进入浏览器、公开仓库或日志。

```sh
export AI_API_KEY='在本机设置的密钥'
export AI_BASE_URL='https://你的服务地址/v1'
export AI_MODEL='你的模型名称'
python3 scripts/serve.py
```

复制 `.env.example` 到 `.env` 填入本机配置即可；环境变量优先于 `.env`。
`.env` 被 Git 忽略，不应上传。Kimi 使用 `https://api.moonshot.cn/v1` 与 `kimi-k2.6`，
按 [官方参数文档](https://platform.kimi.com/docs/api/models-overview) 使用非思考模式，
不强制设置 temperature，避免模型固定参数导致请求失败。
在“旅行风格与习惯”中输入需求，点击“整理我的需求”，核对建议后确认。
请求会把当前偏好和这段文本发送给你配置的 AI 服务；餐厅来源资料不会随此请求发送。
AI 输出不能修改用户选定 / 排除的地点，也不能绕过 MoonBit 的范围校验。

已在 2026-10-11 配置 Kimi K2.6 并验证真实需求提取；公开仓库不包含密钥，其他使用者需自行配置。
本地模拟服务验证 HTTP → 模型输出 → MoonBit 校验链路。用户须确认提议，语义理解可能有偏差。

## 高德地点查询与核对（本机）

在 `.env` 填入 `AMAP_API_KEY`（服务平台为 Web 服务），重启本地服务，打开
`http://127.0.0.1:8787/`，不要直接打开 `web/index.html`。
“真实地点资料”面板提供 31 个大陆省级地区的首发代表城市清单，不是热度榜单。
每批选择 1–5 城，每城最多 20 个景点和 20 家餐厅，仅查询第一页；可在当前城市结束后停止。
城市查询条件、候选记录校验和去重由 MoonBit 实现；Python 负责高德 HTTP 传输。

结果先进入“待核对地点”，保存在本机浏览器。点击“填写并核对”，系统填入名称、地址、
坐标、来源和查询日期；费用、可安排时间、适合人群由用户核对填写。时长预填仅为可编辑建议。
高德费用线索不直接视为门票；缺失值不按免费或全天开放处理。
勾选核对确认后才加入行程候选。可点击“移除虚构示例”只用自定义资料规划；“恢复示例”可恢复演示资料。
“查询路线并重排时间”支持高德步行与公交 / 地铁路线，按返回的时间、距离和人均票价重排已选地点。未查询路段明确标注片区估算。公交票价缺失则报错，不按免费处理。查询发生在本地服务，API key 不进入浏览器。

在线 Pages 不连接此本机接口，也不包含地图密钥。杭州的小规模来源快照随项目提供，每条保留地址、GCJ-02 坐标、来源链接和查询日期；其他批量查询记录只保存在本机浏览器。
数据使用、浏览器暂存和分享须符合 [高德服务要求](https://developer.amap.com/api/webservice/guide/api/search/)。
本地验证地图接口模拟：`python3 scripts/test_maps.py`。

## 自定义餐厅资料

“添加景点或餐厅资料”中填写城市、片区、停留时间、人均费用、可用时间窗口、标签，
以及一个或多个来源链接和核对笔记。
资料作为候选项参与同一套时间、费用和饮食条件规划，用户可以自行选择餐厅。

链接和笔记由用户整理。`素食` / `不辣` / `亲子适合` 是资料标签，不是现场服务保证。
可分别安排午餐（11:00–14:00）和晚餐（17:00–21:00），每天每顿至多一个餐厅；全程过滤同品牌分店与相似短品牌名。若没有可行餐厅则说明缺失，并提示预算尚未包含该顿饭。

## MoonBit 库与数据接口

`src/engine` 实现模型、输入校验、评分、硬约束、行程编排、地点顺序、餐饮条件和预算。
`src/assistant` 实现 AI 提示契约和输出校验；`src/api` 编译为 JavaScript 模块供浏览器与服务器调用。
`web/app.js` 只负责表单、界面事件和下载，`scripts/serve.py` 只负责本地 HTTP 与模型请求。
规划逻辑不在 JavaScript / Python 中重新实现。

MoonBit 使用示例见 `src/main/main.mbt`。公共入口：

```moonbit
@engine.validate(input) // Array[String]
@engine.plan(input)     // Result[Plan, Array[String]]
```

主接口：`plan_json(input_json)`；策略对比：`alternatives_json(input_json)`。
成功返回 `{ "ok": true, "plan": ... }`，失败返回 `{ "ok": false, "errors": [...] }`。
景点 / 餐厅都用 `Place`，`kind` 为 `sight` 或 `food`。
导入文件可以是 `Place[]`，也可以是导出的 `{request, places, plan}`。
恢复导出文件时加载地点资料；条件可在界面重设。

```json
[
  {
    "id": "my-lunch", "name": "你核对过的餐厅", "city": "你的城市",
    "district": "中心", "kind": "food", "tags": ["美食", "不辣"],
    "cost": 50, "duration": 60, "open": 660, "close": 840,
    "indoor": true, "family": true,
    "url": "https://example.com/source",
    "source": "用户核对的人均消费依据和信息日期；未自动验证"
  }
]
```

钱为每人整元人民币；时间为午夜起分钟数，例如 09:00=540。
自动规划使用每人活动、餐饮和市内接驳预算。全团总账计入人数和每人往返交通，不含住宿；全团总预算不足时提示超额，不会暗中削减费用。
重复地点 ID、异常费用、非法时间、缺失来源和非 HTTP(S) 链接会被拒绝。

## 算法与边界

- 决定性贪心算法：按心仪地点顺序优先，其他地点按兴趣 / 费用 / 邻近评分选取。
- 每人活动预算、开放窗口、每日时间、亲子 / 雨天 / 饮食条件、每天景点数为硬约束。
- 每天每顿至多一个餐厅；接近用餐时段时提高优先级，避免普通景点占用最后可行的用餐窗口。旧 API 默认只安排午餐，新界面可分别开启午晚餐。
- 必选地点无法全部安排时返回冲突；普通候选不能安排时给出排除原因。
- 不保证全局最优，算法失败也不证明数学上不存在其他可行行程。
- 已查询路段使用高德预计时间、距离与公交票价（按整元向上取整）；未查询路段回退为同片区 15 分钟/8 元、跨片区 35 分钟/15 元，并明确标注。首站不包含出发点到景点的接驳。
- 普通站间休息 20 分钟，慢游 45 分钟，特种兵 5 分钟。地图方案不是出行当天的实时交通保证；没有天气、预约或节假日闭馆校验。博物馆等复杂营业信息留待人工补充。
- 同一地点全程至多访问一次；实际预算和营业时间应在出行前重新核实。

## 旅行模式、总账与手动调整

- 懒人旅行：默认 10:00–18:00、每天最多 2 个景点、站间休息 45 分钟，美食和同片区优先。
- 特种兵旅行：默认 07:00–22:00、每天最多 6 个景点、站间休息 5 分钟，仍遵守开放时间和活动预算。
- 周末轻旅行：默认 2 天、09:00–18:00、每天最多 3 个景点，每日接驳不超过 60 分钟、已查询路程不超过 10 公里；距离未知的路段明确提示。
- 模式保留当前城市、饮食限制、亲子 / 雨天条件和已选地点；可进一步修改。
- 室内 / 室外是评分偏好；雨天为室内硬约束。步行友好已查询路段限制为步行且不超过 1.5 公里；没有查询的路段仅作片区估算。
- 总账：活动、餐饮和市内交通乘人数，往返交通按人数计算；不含住宿。
- 每站的“调整日期和开始时间”保留其他站安排。MoonBit 校验重叠、接驳、休息、开放时间、预算和餐厅重复；失败不覆盖当前行程。↑↓ 交换当天时间段中的地点，冲突时需先调整时间。
- 出发日期、人数、费用和手动安排保存到本机浏览器；导出 JSON、Markdown、离线路书包含全团总账及日期。重新生成或选择其他方案清除手动安排。

新接口：`plan_with_preferences_json`、`alternatives_with_preferences_json`、`edit_plan_json`、`trip_cost_json`。核心逻辑位于 `src/engine/travel.mbt`，原 `plan_json` 仍兼容旧数据。

## 杭州资料与路线试用

1. 点击“载入杭州真实资料”，保留已有自定义资料，替换杭州虚构样例。默认资料没有擅自标注不辣、素食或亲子适合；开启这些硬条件时，需先补充核实过的标签。
2. 选择旅行模式，分别勾选午餐和晚餐，生成方案。费用 / 时间缺失的地点保留在待补充区，补全后加入候选。
3. 选择公交 / 地铁或步行，点击“查询路线并重排时间”。系统查询当天相邻地点之间的路线，保留日期和地点并重算开始时间。每段成功结果缓存一小时；坐标、方向或方式改变会重新查询。
4. 若完整路线无法在开放时间、每日时段、距离或预算内安排，保留原计划并展示冲突；可减少地点、增加时间或放宽上限。重新生成的新路段尚未查询时仍标注估算。
5. 导出“我的地点资料”可保留候选与待补充记录；JSON / Markdown / 离线路书保留午晚餐标签、路线时间、距离和来源。

更新来源快照：`python3 scripts/collect_hangzhou.py`（需要本地高德密钥，不调用 AI）。脚本按明确地点 / 品牌关键词查询，避免酒店、机场餐厅、同名外县公园与附属入口；对复杂日期时段不自动推断。资料不是热度排行榜。收费景点票价没有来源时仍须补充。

`Place.windows` 为可选的分段营业时间数组，例如 `[{"open":630,"close":840},{"open":1020,"close":1320}]`。缺省时兼容原 `open` / `close`；有分段时不在午休或闭店间隙安排。
新增 `reflow_plan_json`、`route_query_json`、`route_result_json`。旅行接口可传 `meals: {lunch, dinner}` 和 `routing: {mode, strict, distance_limit, routes}`。距离单位米。MoonBit 完成路线输入校验、秒转分钟向上取整、餐饮时段选择和行程重排；Python 只作服务传输与结果字段提取。

参考接口：[高德路径规划](https://lbs.amap.com/api/webservice/guide/api/direction)、[高德地点查询](https://developer.amap.com/api/webservice/guide/api/search/)。
